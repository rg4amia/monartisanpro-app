| --- | --- |

| `technique/` | Architecture Hostinger, diagramme de flux Mermaid, plan de refactoring mobile |
| `archive/` | Documents historiques conservés pour mémoire (anciens prompts, prototypes Gemini) |

Les scripts d'outillage (build APK, génération des données géographiques) sont dans `scripts/`.
