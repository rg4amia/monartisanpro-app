# Marker Assets

This directory contains marker icons for the Yandex MapKit integration.

## Required Markers

1. **marker_default.png** - Blue marker for regular artisans
2. **marker_nearby.png** - Yellow/gold marker for nearby artisans

## Recommended Sizes

- 1x: 48x48 px
- 2x: 96x96 px
- 3x: 144x144 px

## Creating Markers

You can create these markers using:
- Design tools (Figma, Sketch, Adobe XD)
- Icon libraries (Material Icons, Font Awesome)
- Online generators (https://mapicons.mapsmarker.com/)

## Temporary Solution

For now, the app will use default Yandex markers until custom PNG files are added.
To add custom markers, simply place PNG files with the names above in this directory.
